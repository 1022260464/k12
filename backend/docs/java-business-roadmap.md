## 验收标准

- 学生、教师、管理员分别验证授权和越权分支，不能只用 admin 调接口。
- 不依赖正在运行的共享服务完成单元测试；真实数据库与消息队列另做集成测试。
- 状态迁移与写操作必须有事务边界，并验证重复请求、并发和异常路径。
- `.env` 和真实密钥不提交；文档与 OpenAPI 使用同一套中文接口说明。
- 一项业务完成后更新本清单，尚未完成的条目不标记为完成。
