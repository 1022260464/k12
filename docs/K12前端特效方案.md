## 一、六种特效速览

| # | 特效 | 一句话效果 | 技术 | 成本 |
|---|------|-----------|------|------|
| 1 | 粒子动效 | 背景漂浮光点缓慢上浮、近距淡线相连，像「知识的火花」 | Canvas 2D + rAF | 低（60fps，CPU <3%） |
| 2 | 鼠标跟随柔光 | 一大团柔光跟着鼠标走，页面像被无形的灯照亮 | fixed div + 径向渐变 + mix-blend:screen + lerp | 极低 |
| 3 | 流光边框 | 渐变高光透过玻璃整体流动，梦幻彩晕 | conic-gradient + @property --ang 旋转 | 极低（GPU 合成） |
| 4 | 渐变星空背景 | 极光渐变 26s 缓慢流动 + 星点各自闪烁 | 多层 radial-gradient + background-position 动画 + JS 撒星 | 极低 |
| 5 | 毛玻璃卡片 | 半透明磨砂、透出背景光色、顶部内高光 | backdrop-filter: blur(16px) saturate(140%) | 中（大面积慎用） |
| 6 | 按钮 hover | 主按钮浮起+扫光，次按钮填充变色，金色按钮光晕 | transition + ::after 扫光 | 极低 |

## 二、逐项实现要点（可直接抄）

### 1. 粒子动效（Canvas）

- 数量：桌面 40～72 颗 / 手机减半（20～36）；每颗 `vx∈±0.25`、`vy=-0.1~-0.38`（缓慢上浮）
- 近距连线：两点距离² < 110² 时画线，透明度 `0.08×(1-d/110²)` 随距离衰减
- 循环出画：越界从对侧回来（`y<-8 → y=H+8`）
- **必须做**：`prefers-reduced-motion` 时不启动；组件卸载时 `cancelAnimationFrame` + 移除 resize 监听
- **项目内已落地**：`src/components/ParticleField.jsx`，挂在 `HomePage` 根节点，`z-index:-1` 压在内容下、与 body 云层/点阵装饰同层；小学=金/青/蓝，中学=紫/青/绿

### 2. 鼠标跟随柔光

```css
#glow{position:fixed;width:520px;height:520px;border-radius:50%;pointer-events:none;z-index:1;
  transform:translate(-50%,-50%);filter:blur(18px);mix-blend-mode:screen;transition:opacity .4s;
  background:radial-gradient(circle, rgba(120,150,255,.26) 0%, rgba(140,110,255,.11) 38%, transparent 68%)}
```
跟随用 lerp（每帧 `cur += (target-cur)*0.08`）才有「拖影感」，直接赋值会显得生硬。

### 3. 流光边框（定稿 = 渐变透玻璃版）

```css
.fx-card{position:relative;border-radius:20px;padding:1.6px;
  background:conic-gradient(from var(--ang,0deg),
    transparent 0deg, rgba(143,176,255,.9) 40deg, rgba(201,168,255,.95) 70deg,
    transparent 130deg, transparent 200deg, rgba(255,209,102,.85) 250deg, transparent 310deg);
  animation:spin 5s linear infinite}
@property --ang{syntax:'<angle>';initial-value:0deg;inherits:false}
@keyframes spin{to{--ang:360deg}}
.fx-card .inner{border-radius:19px;background:...半透明磨砂...;backdrop-filter:blur(16px)}
```

**坑位记录（三次迭代教训）**：
- 渐变画在卡片底层 + 玻璃半透明 ⇒ 玻璃透出旋转渐变 → 整卡在流（当前定稿效果，喜欢就保留）
- 若要「只沿边框流」：渐变放 `::before` + mask 镂空（`mask:linear-gradient(#fff 0 0) content-box, linear-gradient(#fff 0 0); mask-composite:exclude`），卡身就干净了
- 若要「宝石抛光单扫光」：conic 只留一段 亮芯+尾迹（transparent→0.35 白热 0.95→尾迹 0.55→transparent 148deg→360deg），6s 一圈
- 多卡片用 `animation-delay:-1.6s/-3.1s` 错开相位，避免齐步走

### 4. 渐变星空背景

```css
#aurora{position:fixed;inset:-20%;z-index:0;pointer-events:none;
  background:radial-gradient(1100px 700px at 75% -5%,#5a4bb8 0%,transparent 55%),…多层…;
  background-size:180% 180%;animation:drift 26s ease-in-out infinite alternate}
@keyframes drift{0%{background-position:0% 0%}100%{background-position:100% 100%}}
.star{position:absolute;border-radius:50%;background:#fff;animation:tw linear infinite}
@keyframes tw{0%,100%{opacity:.15;transform:scale(.8)}50%{opacity:.95;transform:scale(1.15)}}
```
星点 JS 撒 46（手机）～96（桌面）颗，每颗随机 `animation-duration:2~6s` + 负 delay，避免同步闪。

### 5. 毛玻璃卡片

```css
.inner{background:rgba(255,255,255,.07);
  backdrop-filter:blur(16px) saturate(140%);-webkit-backdrop-filter:blur(16px) saturate(140%);
  border:1px solid rgba(255,255,255,.14);
  box-shadow:inset 0 1px 0 rgba(255,255,255,.22), 0 12px 40px rgba(10,12,40,.35)}
```

- `inset 0 1px 0 rgba(255,255,255,.22)` 是顶部内高光，玻璃质感一半靠它
- K12 浅色主题下用深色玻璃底（如 `rgba(30,34,80,.92)`）保证文字对比度，只透 8% 背景色
- **大面积/多层嵌套 backdrop-filter 会掉帧**，一屏 2～3 块为限

### 6. 按钮 hover 三连

```css
.btn{background:linear-gradient(120deg,var(--acc),var(--acc2));position:relative;overflow:hidden;
  transition:transform .22s cubic-bezier(.34,1.56,.64,1), box-shadow .22s}
.btn::after{content:"";position:absolute;top:0;left:-80%;width:50%;height:100%;
  background:linear-gradient(105deg,transparent,rgba(255,255,255,.45),transparent);
  transform:skewX(-20deg);transition:left .5s ease}
.btn:hover{transform:translateY(-3px) scale(1.03);box-shadow:0 10px 30px rgba(110,130,255,.55)}
.btn:hover::after{left:130%}   /* 高光扫过 */
.btn:active{transform:translateY(0) scale(.98)}  /* 按下回弹 */
.btn.ghost:hover{background:linear-gradient(120deg,var(--acc),var(--acc2))}  /* 次按钮填充 */
```
`cubic-bezier(.34,1.56,.64,1)` 是回弹曲线，hover 浮起的「Q弹感」全靠它。

## 三、K12 落地建议（已与用户对齐的方向）

| 位置 | 建议开什么 |
|------|-----------|
| 登录弹层背景 / 未登录首页 / 首页头图 | 粒子 + 柔光 + 星空 全开 |
| 信息卡片（课程卡、勋章卡、AI 回复卡） | 毛玻璃；重点卡可加流光 |
| 全站按钮 | hover 三连（主=浮起+扫光，次=填充）——提升最明显、零风险 |
| 课程正文 / 答题页 / 低年级学习页 | **保持安静**（粒子减半或关闭），避免分散注意力 |
| 勋章/成就/闯关结算 | 流光边框点睛，让重点「贵」起来；不可满屏都用 |

**通用红线**：一律尊重 `prefers-reduced-motion`；手机端粒子/星点减半；一屏动效不超过两层。
