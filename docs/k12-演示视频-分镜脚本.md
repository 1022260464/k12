# K12 演示视频 · 逐秒分镜脚本 v2（全功能版，≤5 分钟，目标 4:50）

> **v2 变化**：不再讲故事线，改为**功能全覆盖**——学生端 17 页 + 管理端核心页全部入镜。
> **倍速策略**：三档制——① 等待/加载/打字/走路 → **硬切剪掉**（不占时长）② 一般操作 → **1.3–1.5x**（观众能看清点了什么）③ 高光六瞬间 → **原速 + 圈注**。全片没有超过 1.5x 的地方，"稍微加一点倍速"指的就是这一档。

## 一、录制方法（先读这个）

1. **分段录，绝不一条过**。16 个镜头 = 16 个独立素材文件，每段前后各留 3 秒。分段才能对每段独立剪掉等待、独立调速——这是 5 分钟装下所有功能的唯一方法。
2. **能剪的不快进**。页面加载、登录跳转、打字一律后期硬切，画面上"点完下一个瞬间就是结果"。
3. **干跑计时再正式录**。不录屏先把 16 段走一遍、手机计时；某段实际操作超过脚本时长 ×1.4，就砍该段的展示内容（不是加快倍速）。
4. **口播后期配**。先剪画面再对着画面配音（约 700 字），节奏才压得进去；全程字幕。
5. **环境**：1080p、浏览器缩放 100%、无痕窗口、关系统通知、30fps、大光标（macOS 辅助功能里调）+ 点击高亮（Screen Studio 或 OBS 插件，后期圈注也可）。
6. **预置**：学生端/管理端两个浏览器窗口各自提前登录好；wskid01 当日积分前后值记在纸上；录前跑一遍演示预检（应 21/0）；E2E 绿。
7. **素材冗余**：镜头 4（问问小智）和 11（闯关积分）是核心，各录两条备选。
